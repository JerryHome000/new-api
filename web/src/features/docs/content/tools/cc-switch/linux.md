## 1. 安装

1. 打开 CC-Switch 的 GitHub Releases 页面；
2. 按发行版下载安装包：Ubuntu / Debian 用 `.deb`，其他桌面发行版优先用 `AppImage`；
3. 安装或赋予执行权限后启动。

## 2. 添加 {{SITE_NAME}}

| 工具        | Base URL          |
| ----------- | ----------------- |
| Claude Code | `{{BASE_URL}}`    |
| Codex       | `{{BASE_URL}}/v1` |
| OpenCode    | `{{BASE_URL}}/v1` |

API Key 填你的 {{SITE_NAME}} Key。

在 Windows 上，Codex 桌面版集成在 ChatGPT 客户端里。

## 从 Microsoft Store 安装

1. 打开 Microsoft Store，搜索 `ChatGPT`；或直接打开商店页面：

   ```text
   https://apps.microsoft.com/detail/9plm9xgg6vks
   ```

2. 点击安装，完成后从开始菜单打开 ChatGPT。

> **注意** · 只从 Microsoft Store 或 OpenAI 官方渠道安装，不要运行来源不明的安装包。

## 接入 {{SITE_NAME}}

桌面版和 CLI 读取同一份配置（`%USERPROFILE%\.codex\`）。按 [Codex Windows 教程](/docs/tools/codex/windows) 写好 `config.toml` 和 `auth.json`，或使用 [一键配置](/docs/tools/codex/one-click)。

写完配置后，**彻底退出** ChatGPT 桌面端（包括托盘图标）再重新打开。

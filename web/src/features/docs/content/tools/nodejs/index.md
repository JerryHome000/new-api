这里介绍的工具几乎都运行在 Node.js 上。第一次接触的话，直接装官网的 LTS 版本，并尽量保持较新，兼容性最好。

## 需要什么版本

- **最低**：Node.js 18 及以上。
- **推荐**：Node.js 24 LTS。新版 OpenClaw 要求 24.16 以上，其余工具 22 以上即可。

## 检查是否已经安装

在终端执行：

```bash
node -v
npm -v
```

两条命令都能输出版本号，就说明已经装好，可以直接去安装工具。

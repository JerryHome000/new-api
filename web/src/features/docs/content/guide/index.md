## 它是怎么工作的

{{SITE_NAME}} 位于你的工具和模型厂商之间，负责转发请求和返回结果：

```text
你的工具 / 代码  →  {{SITE_NAME}}  →  模型厂商（Anthropic、OpenAI、Google 等）
```

这样接入的好处：

- **一套配置**：同一个 Key 可以调用不同厂商的模型，切换模型只改模型名。
- **兼容主流协议**：支持 OpenAI 格式和 Anthropic 格式，大多数工具无需改代码即可接入。
- **统一账单**：所有模型的用量都记在同一个账户里，在控制台随时查看。

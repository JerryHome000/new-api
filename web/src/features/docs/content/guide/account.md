从注册到在工具里用上 Key，一共四步。

## 1. 注册并登录

打开 [注册页面](/sign-up)，按提示完成注册后登录。注册不收费，只有实际调用模型时才会扣除余额。

## 2. 进入控制台

登录后进入 [控制台](/dashboard)。接入时最常用的三个入口：

- **API 密钥**：创建和管理 Key。
- **钱包**：充值、兑换码兑换。
- **使用日志**：查看每一次调用的模型、Token 和费用。

## 3. 创建 API Key

API Key 是你调用模型的凭证，配置 Claude Code、Codex、OpenCode 等工具时都要用到。

1. 打开控制台的 [API 密钥](/keys) 页面。
2. 点击「添加令牌」。
3. **选择分组**。分组决定可用模型和价格倍率，详见 [分组与计价](/docs/guide/pricing)。
4. 填一个能看出用途的名称，例如 `codex-laptop`、`claude-work`。
5. 创建后复制 Key（以 `sk-` 开头）。

> **注意** · Key 等同于账户密码。不要提交到 Git 仓库、截图分享或发到群里；一旦泄露，立即在控制台删除并重新创建。

### 分组怎么选

不同分组的差别通常有三点：

- 能调用哪些模型；
- 价格倍率（例如 0.5x、1.2x）；
- 是否只适合特定工具。

> **待补充** · 本站各分组的选择建议（哪个分组适合哪个工具）。

## 4. 在工具里使用 Key

接入任何工具都只需要两样东西：

- **API Key**：刚刚创建的 `sk-...`。
- **Base URL**：{{SITE_NAME}} 的接口地址。

Base URL 有两种写法，取决于工具使用的协议：

| 写法       | 地址              | 常见于                               |
| ---------- | ----------------- | ------------------------------------ |
| 不带 `/v1` | `{{BASE_URL}}`    | Claude Code 等 Anthropic 协议工具    |
| 带 `/v1`   | `{{BASE_URL}}/v1` | Codex、OpenAI SDK 等 OpenAI 协议工具 |

不用自己判断，照着 [工具部署](/docs/tools) 里对应工具的教程填写即可。

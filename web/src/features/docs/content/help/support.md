## 怎么提问更快得到答复

**请提供：**

- 问题从什么时候开始、具体的报错信息、已经试过的办法；
- 使用的工具和版本、操作系统；
- 相关配置（**隐去 Key 等敏感信息**）；
- 报错截图或日志。

**请避免：**

- 只说“不能用了”“有问题”，却没有任何报错信息；
- 在公开场合贴出 API Key；
- 重复发送同一个问题。

## 反馈建议

- **功能建议**：说明使用场景和期望的效果；
- **Bug 报告**：写清复现步骤、预期结果和实际结果、环境信息和相关日志；
- **文档改进**：指出具体页面和位置，说明哪里有问题。

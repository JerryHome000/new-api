## 热门问题

### 怎么选模型？

按任务难度来：简单任务用轻量模型（mini / haiku / flash 一类），日常开发用标准版本，复杂的架构和推理任务再用旗舰模型。实时的模型和价格见 [模型广场](/pricing)。

### 怎么省钱？

选对模型、限制输出长度、把提示词写清楚、长对话定期清理上下文。更多技巧见 [分组与计价](/docs/guide/pricing#省钱技巧)。

### 连不上怎么办？

依次检查网络、Key、Base URL 和账户余额，详见 [疑难杂症](/docs/help/troubleshooting)。

### 回答质量不理想？

换一个更强的模型，给足上下文，把需求拆成更小、更明确的步骤。

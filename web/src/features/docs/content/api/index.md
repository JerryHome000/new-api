## 视频生成

视频生成耗时较长，请使用异步调用：先创建任务拿到 `id`，再用这个 `id` 轮询状态，不要让一个创建请求一直等到生成结束。

| 模型系列 | 能力                      | 文档                                      |
| -------- | ------------------------- | ----------------------------------------- |
| Veo      | 文生视频 / 图生视频       | [Veo 视频](/docs/api/veo-video)           |
| Seedance | 文生视频 / 参考素材生视频 | [Seedance 视频](/docs/api/seedance-video) |

> **待补充** · 视频模型对应的分组与每秒参考价格。

异步调用流程：

1. `POST /v1/videos` 创建任务；
2. 保存响应里的 `id`；
3. 每隔 10–15 秒请求一次 `GET /v1/videos/{id}`；
4. 状态变成 `completed` 后，用返回的 `video_url` 下载视频。

## 开始调用

1. [注册账号并创建 Key](/docs/guide/account)；
2. 按能力选择 Key 的分组和模型；
3. 用上表对应的 Base URL 和接口格式发起请求；
4. 在控制台的 [使用日志](/usage-logs) 查看用量和扣费明细。

模型与价格会随上游调整，请以 [模型广场](/pricing) 和 `GET /v1/models` 的实时返回为准。

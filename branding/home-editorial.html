07 / FAQ

Cheap is fine.
Clear is better.

便宜归便宜，账还是要问明白。

01需要自己准备 OpenAI、Anthropic 或 Google 账号吗？

不需要。注册 Aion、创建一个 API Key，就能从同一个入口调用所有开放的模型。上游账号、配额、网络都由我们维护。

02怎么计费？

按 token，每个模型的输入 / 输出单价都列在模型广场。请求结束立即扣费，控制台能看到每一笔的模型、token 数和金额。没有月费，没有最低消费。

03我现有的代码要改多少？

两行：Base URL 和 Key。OpenAI SDK、Anthropic SDK、Gemini SDK 都直接兼容，Claude Code、Codex、Cursor、Cherry Studio 这类客户端只改设置。

04上游挂了怎么办？

同一个模型背后挂了多条上游线路，一条失败自动切到下一条。你那边看到的只是一次正常响应。

05调用不正常去哪里看？

控制台的「使用日志」按请求列出状态码、耗时、模型和错误原因；「数据看板」看整体错误率和延迟。

06支持流式和多模态吗？

支持。Chat Completions、Responses、Messages 三种接口都支持 stream；图片、音频、embedding、rerank 按模型能力开放。

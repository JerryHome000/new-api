04 / FAQ

常见问题

01需要自己准备 OpenAI、Anthropic 或 Google 账号吗？

不需要。注册 Omni、创建一个 API Key，就能调用所有开放的模型。上游账号、配额、网络都由我们维护。

02怎么计费？

按 token，每个模型的输入 / 输出单价都列在模型页。请求结束立即扣费，没有月费和最低消费。

03现有代码要改多少？

两行：Base URL 和 Key。OpenAI、Anthropic、Gemini 三家 SDK 直接兼容；Claude Code、Codex、Cursor 这类客户端只改设置。

04调用出问题去哪里看？

控制台「使用日志」按请求列出状态码、耗时、模型和错误原因；「数据看板」看整体错误率和延迟。
